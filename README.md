# 🧩 Shikaku

Японская логическая головоломка с тёмной и светлой темами,
шестью режимами игры и неоновым интерфейсом.

> *Разрезай · Считай · Побеждай*

---

## 🎯 Что это за игра

**Shikaku** (яп. 四角に切れ — «разрежь на квадраты») — классическая японская
логическая головоломка, которую часто ставят в один ряд с судоку.

Цель — **разрезать всё поле на прямоугольники** так, чтобы в каждом оказалась
ровно одна цифра, а площадь прямоугольника точно совпадала с этой цифрой.

Проект написан на **чистом Python** с использованием стандартной библиотеки
Tkinter. Никаких игровых движков, никаких веб-фреймворков. Только Python,
немного Pillow для графики и любовь к логическим головоломкам.

---

## 📐 Правила

1. Поле — квадрат N×N с несколькими цифрами в клетках.
2. Каждая цифра — площадь будущего прямоугольника, который её покрывает.
3. Прямоугольник может быть любой формы (включая квадрат),
   но его площадь = цифре внутри.
4. Прямоугольники не пересекаются и не оставляют пустых клеток.
5. Никаких подсказок «1» — минимальный размер фигуры 2 клетки.
6. Победа — когда всё поле корректно разбито.

Примеры:
- Число **6** → прямоугольник **2×3** или **1×6** или **3×2**
- Число **2** → прямоугольник **1×2** или **2×1**
- Число **9** → квадрат **3×3** или прямоугольник **1×9**

## 🎮 Режимы игры

### 🎯 Обычная игра
Решай один пазл выбранного размера. Время идёт, рекорд сохраняется.
Идеально для тренировки.

### ⚡ Серия из 5
Пройди 5 уровней одного размера подряд. Время не сбрасывается между
уровнями — все 5 идут в общий рекорд. Отдыхать некогда.

### 📈 Растущая серия
Шесть уровней с растущим размером:
3×3 → 6×6 → 9×9 → 15×15 → 25×25 → 30×30.
Время копится, подсказки обновляются на каждом этапе. Настоящий марафон.

### ⏱ На время
Тот же пазл, но с ограничением по времени. На 3×3 — 15 секунд,
на 30×30 — 8 минут. Успел — рекорд по остатку. Не успел — экран проигрыша.

### 👁 Слепой режим
Прямоугольники не подсвечиваются цветом — только контуры.
Настоящее испытание на внимательность. Цвета проявляются после победы.

### 📅 Ежедневный вызов
Один пазл в день на каждый размер. Пазл одинаковый у всех игроков
и меняется в полночь. Проходи каждый день, чтобы поддерживать серию.

## ✨ Возможности

### Визуал
- Две парные темы: тёмная (неоновая фиолетово-розовая)
  и светлая (мягкая лилово-белая)
- 18 обоин — своя для каждого контекста (меню, 6 размеров, правила,
  настройки), автоматическая смена в зависимости от экрана
- Пользовательские обои — можно загрузить свой .jpg для любого экрана
  через настройки
- Неоновое свечение сетки и прямоугольников
- Кастомные шрифты: Clash Display, Jost, Schueler SuperXP
- Плавные анимации: выезд карточки победы, прокрутка времени,
  пульсация акцента
- Красная плавная пульсация краёв экрана при ошибке

### Геймплей
- 6 режимов игры
- 6 размеров поля: 3×3, 6×6, 9×9, 15×15, 25×25, 30×30
- Подсказка — ставит один правильный прямоугольник, штраф +15 секунд
- Проверка — подсвечивает неправильные прямоугольники, штраф +5 секунд
- ПКМ-удаление любого прямоугольника
- Undo — отмена последнего хода
- Автоскейл клетки — поле всегда влезает в окно
- Автосохранение партии каждые 15 секунд

### Прогресс
- Рекорды по каждому режиму и размеру отдельно
- Серия дней — счётчик ежедневных вызовов подряд
- Рекорды для растущей серии — отдельная таблица

### Настройки
- Тема (тёмная / светлая)
- Размер клетки (компактный / обычный / крупный)
- Анимации вкл/выкл
- Автосохранение вкл/выкл
- Звук вкл/выкл
- Смена обоев для каждого контекста

## 🛠 Установка

Требования:
- Python 3.10+
- Pillow

Шаги:

1. Клонируй репозиторий:
   ```
   git clone <ссылка на твой репозиторий>
   cd shikaku
   ```

2. Установи Pillow:
   ```
   pip install Pillow
   ```

3. Сгенерируй обои (один раз):
   ```
   python make_wallpapers.py
   ```
   Это создаст 18 картинок в `data/wallpapers/`.

4. Запусти игру:
   ```
   python bin/main.py
   ```

Всё.

## 🚀 Запуск

Обычный запуск:
```
python bin/main.py
```

Запуск как модуль:
```
python -m shikaku
```

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| ЛКМ + протяжка | Нарисовать прямоугольник |
| ПКМ | Удалить прямоугольник под курсором |
| Ctrl+Z | Отменить последний ход |
| Ctrl+N | Новая партия |
| Ctrl+S | Сохранить партию |
| Ctrl+R | Начать заново |
| H | Подсказка |
| C | Проверка |
| Space | Пауза (в режиме «На время») |
| Esc | Вернуться в меню |
| F11 | Переключить полноэкранный режим |
| Enter | Продолжить (между уровнями серии) |

Принципы архитектуры:

- `storage/` — сохранение в JSON-файлы.
- `ui/` — весь визуал. Обращается к `core` и `storage`.
- Java-style раскладка — `src/main`, `bin/` — для привычности.

## 📦 Сборка в .exe

Проект можно собрать в `.exe` через PyInstaller. Тогда игру можно передать
друзьям, у которых нет Python.

Сборка:

```
pip install pyinstaller
python -m PyInstaller --onedir --windowed --name Shikaku --icon=shikaku.ico --add-data "data/fonts;data/fonts" --add-data "shikaku.ico;." --paths "src/main" --hidden-import shikaku --hidden-import shikaku.ui --hidden-import shikaku.ui.app --hidden-import shikaku.ui.theme --hidden-import shikaku.ui.menu_screen --hidden-import shikaku.ui.game_screen --hidden-import shikaku.ui.board_view --hidden-import shikaku.ui.settings_screen --hidden-import shikaku.ui.rules_screen --hidden-import shikaku.ui.modes_screen --hidden-import shikaku.core --hidden-import shikaku.core.board --hidden-import shikaku.core.generator --hidden-import shikaku.core.validator --hidden-import shikaku.core.types --hidden-import shikaku.storage --hidden-import shikaku.storage.records --hidden-import shikaku.storage.daily --hidden-import shikaku.storage.savegame --hidden-import shikaku.storage.settings bin/main.py
```

Готовый `.exe` появится в `dist/Shikaku/`. Копируй всю папку целиком —
там `_internal/`, `data/`, `Shikaku.exe`.

Передача друзьям: другу нужна вся папка `Shikaku/`, а не только `.exe`.
Windows может показать предупреждение SmartScreen — просто нажать
«Подробнее» → «Выполнить в любом случае».
